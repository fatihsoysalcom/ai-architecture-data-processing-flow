# AI Architecture Data Processing Flow

This Python script demonstrates a simplified end-to-end data processing pipeline for an AI application. It simulates data generation, preprocessing, model training, and inference, highlighting the distinct stages and their importance in AI architecture.

## Language

`python`

## How to Run

Save the code as `ai_data_pipeline.py` and run it from your terminal using: `python ai_data_pipeline.py`
